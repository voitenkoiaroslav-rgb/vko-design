Установка:
1. Распакуйте архив.
2. Скопируйте содержимое папки vko-work в корень существующего проекта (с заменой файлов).
3. Убедитесь, что папка public/images/travel92 содержит изображения из архива.
4. В PowerShell выполните: npm.cmd install
5. Запустите: npm.cmd run dev
6. Откройте: http://localhost:3000/projects/travel-92

Главная страница app/page.tsx и карточки проектов не изменялись.

Примечание по содержанию:
Travel 92 оформлен как iOS Concept / Design Concept, а не как опубликованное iOS-приложение. В кейсе нет выдуманных метрик запуска, пользовательских тестов или бизнес-результатов.
