# V/KO DESIGN — Portfolio

Минималистичное портфолио UX/UI и Product Designer на Next.js.

## Запуск локально

1. Установите Node.js LTS.
2. Распакуйте проект и откройте папку в терминале.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте http://localhost:3000

## Структура

- `app/page.tsx` — главная страница
- `app/projects/[slug]/page.tsx` — шаблон подробного кейса
- `data/projects.ts` — данные проектов
- `components/` — повторно используемые компоненты
- `public/images/` — изображения

## Как добавить проект

Добавьте новый объект в `data/projects.ts`, задайте уникальный `slug` и поместите изображения в `public/images/`. Страница проекта создастся автоматически по адресу `/projects/slug`.

## Перед публикацией

- Замените концептуальные SVG-обложки реальными экранами своих проектов.
- Замените `hello@vko.design` на рабочий адрес.
- Уточните биографию, навыки и контакты.
- Не публикуйте исследовательские выводы, интервью или метрики, если они не проводились или не подтверждены.
